# Changelog

All notable changes to uc-processes are recorded in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this repository uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.0] - 2026-10-27

### Added

- Guide: Managing the Vishpala release key, version 0.1.3, under `en-ca/docs/guides/releases/`, with the earlier 0.1.3 text under `artifacts/`.
- Guide: Generating a strong passphrase, version 0.1.1, with 0.1.0 under `artifacts/`.
- Process: Creating a New Repository with uc-automa, version 0.1.0.
- Process: Licensing a Repository with REUSE, version 0.1.0.
- Process: Production-ready Droplet for multi-site Caddy and Eleventy hosting, version 0.1.0, and Set up a Production-Ready Droplet.
- UC Radar Telemetry Trace Procedure, version 0.1.0, in draft, under `en-ca/docs/processes/uc-radar/`.

## [0.1.1] - 2026-10-22

### Added

- The release scripts `bump-version.py`, `cut-release.py`, `publish-release.py` and `test_publish_release.py`, copied unmodified from sat-doc-automa at commit fc0b72a.
- `.gitignore` from sat-doc-automa's release-artifacts defaults, ignoring `dist/` and Python caches.
- A Releases section in the README.

## [0.1.0] - 2026-10-22

### Added

- README describing uc-processes, who maintains it, how it relates to uc-radar and uc-automa, and its list of processes.
- Process: From Question to Practice, version 0.1.0, in draft.
- VERSION file holding 0.1.0.
- Creative Commons Attribution 4.0 International licence text for the documents.
